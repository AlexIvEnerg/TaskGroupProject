# 📖 Описание проекта
Консольное Java-приложение для управления коллекцией автомобилей.

Проект реализует:
- заполнение коллекции автомобилей (ручное / случайное / из файла)
- сортировку по различным полям
- запись данных в файл
- дополнительные алгоритмы обработки данных
- многопоточную обработку (CountService)
- ручные тесты без JUnit

# 🧠 Архитектура проекта

## 🎯 Strategy Pattern (сортировка)

Пакет:

comparator/


Реализации:
- CarPowerComparator
- CarModelComparator
- CarYearComparator

Используются в:
- SelectionSort

📌 filler/ (Strategy для заполнения данных)

Реализации стратегий заполнения коллекции:

- DataFiller — общий интерфейс/абстракция
- ManualFiller — ручной ввод данных
- RandomFiller — генерация случайных автомобилей
- FileFiller — загрузка из файла

---

## 🏗 Builder Pattern

Файл:

model/Car.java


Особенности:
- безопасное создание объектов через Builder
- валидация входных данных:
    - модель не может быть null
    - мощность должна быть корректной

---

## 📦 Хранилище данных


model/CarStorage.java


Используется как контейнер для кастомной коллекции автомобилей.

---

## 🛠 Util


util/FileWriterHelper.java


Утилита для работы с файлами.


util/CountService.java


### 🧠 Многопоточность (CountService)
Реализует:
- разбиение списка на части
- использование ExecutorService
- параллельный подсчёт количества автомобилей по модели
- объединение результатов через Future
